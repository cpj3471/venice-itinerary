# Venice Film Festival — Trip Itinerary

An interactive, self-contained itinerary for the Audible team trip to the Venice International Film Festival (3–6 September 2026).

`index.html` is the whole app: day-by-day plan, interactive map (hotels, venues, water-bus/taxi stops), step-by-step airport and local transfers, contacts, passes, live clocks and a countdown to the next event. Edits are saved in your browser; you can export/import them and download a Word version.

## View it
Open `index.html` in any browser, or visit the published GitHub Pages link. On iPhone: open in Safari, then Share → Add to Home Screen.

Notes: the map and Word-export features load small libraries online, so they need a connection; everything else works offline.
